Security & verification

Voltrix is a beta build. Here is how to check it before running it — and we never ask you to turn off your antivirus.

Verify before you run

Scan the file on VirusTotal and compare the published SHA-256 hash with the one on our Discord. If they match, the file you downloaded is the one we released.

Keep Windows Defender and your antivirus fully enabled. We do not ask you to disable protection or add exclusions.

SmartScreen warning?

A new, unsigned build can trigger a SmartScreen reputation prompt. If that worries you, don't run it — verify the hash first, or wait for a signed release.

We're working on a code-signing certificate so future builds are signed and this prompt disappears for everyone.
